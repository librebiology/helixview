HelixView User Guide

A practical reference for biologists. No programming required.

Opening files

HelixView opens on the last session automatically. To open a new file:

  • Click Open in the toolbar, or press Ctrl+O
  • Drag and drop a file from your file manager onto the window
  • Use File → Fetch from NCBI… to download a sequence by accession number

Supported formats: FASTA, GenBank (.gb/.gbk), Clustal (.aln), PHYLIP, Stockholm, AB1 chromatogram traces.

To open a project (all open files + window layout), use Open Project and choose a .hvproj file.

Editing sequences

  • Insert gap: click on a cell and press Space or -
  • Delete gap: select a gap cell and press Backspace or Delete
  • Rename a sequence: double-click the sequence name in the left column
  • Find a motif: press Ctrl+F and type — matches highlighted in the grid
  • Undo / Redo: Ctrl+Z / Ctrl+Y

Exporting

Use the Export toolbar tab or Ctrl+E:

  • FASTA — plain sequences, current alignment
  • Text alignment — blocked format with ruler and position numbers; adjustable line width
  • SVG — shaded alignment, vector, scales to any size
  • PDF — shaded alignment, ready for publication or lab reports

Workflow: RNA stem–loop analysis

Best results with ≥20 aligned sequences of the same RNA gene (e.g. 16S rRNA, 5S rRNA, tRNA).

Step-by-step

  1. Open a multi-sequence RNA FASTA alignment (Ctrl+O).
  2. In the toolbar, open the Analysis tab and click Mutual Information.
  3. Adjust Top pairs and Min observations if needed, then click Run MI.

    MI uses all CPU cores — on a typical laptop this takes a few seconds for a 100-sequence, 1500-column alignment.

  4. Switch to the Covariation tab. Green-highlighted rows are candidate stem pairs (≥2 Watson–Crick pair types, ≥50% WC fraction by default).
  5. Use the Min WC types and Min WC % sliders to tighten or loosen the threshold. The table updates instantly.
  6. Go back to the Alignment view. Toggle Cov Arcs in the View toolbar tab to see arcs connecting covarying column pairs above the entropy strip.
  7. If you edit the alignment after running MI, an amber warning strip will appear reminding you to re-run.

Workflow: Plasmid annotation

  1. Open a GenBank file (.gb or .gbk). pUC19 from NCBI (accession L09137) is a good test case.
  2. Click the Plasmid tab. The circular map renders with all annotated features colour-coded by type.
  3. Click any arc on the map, or click a row in the feature list on the right, to select a feature.
  4. Edit the feature name, start/end positions, or colour using the panel that appears below the feature list. Enter a hex colour code directly in the #RRGGBB field, or pick from the 16-swatch palette.
  5. Click Apply to commit your changes. The map updates immediately.
  6. Use + New to add a blank feature; click ✕ next to a feature to delete it.
  7. Save the file as GenBank to preserve annotations (Ctrl+S).

Workflow: Local BLAST search

Requires BLAST+ to be installed and makeblastdb / blastn / blastp on your system PATH. Download from NCBI BLAST+.
  1. Open the Analysis panel → BLAST section.
  2. Click Create Local DB… and select a FASTA file to use as the database. HelixView detects protein vs nucleotide automatically.
  3. Once the DB is built, select a query sequence in the alignment view.
  4. Click Run Local BLAST. Hits appear in the results table below.
  5. Double-click any hit to jump to that region in the alignment.

Workflow: Command-line tools

The helixview-cli binary is installed alongside the main application. Open a terminal and run:

# Print alignment statistics
helixview-cli stats sequences.fasta

# Per-column Shannon entropy (tab-separated)
helixview-cli entropy sequences.fasta --min-entropy 1.0

# Consensus sequence (IUPAC codes)
helixview-cli consensus sequences.fasta --method iupac

# Mutual information + WC covariation
helixview-cli mi sequences.fasta --top 20 --min-cov 0.5

# NxN pairwise identity matrix (percent)
helixview-cli identity sequences.fasta --percent

# Convert format by file extension
helixview-cli convert input.fasta output.clustal

Run helixview-cli --help or helixview-cli <command> --help for full option lists.
