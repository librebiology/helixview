HelixView

Free, open-source sequence alignment editor for Windows, macOS and Linux.
A modern replacement for BioEdit.

Download View source

Features

  • Alignment editor — open, edit and export FASTA, Clustal, GenBank, PHYLIP, Stockholm; insert/delete gaps; full undo/redo
  • Colour schemes — nucleotide, amino acid, Clustal X, and conservation-based colouring
  • Entropy strip — per-column Shannon entropy displayed live below the alignment
  • RNA covariation (MI) — mutual information for all column pairs; Watson–Crick scoring highlights stem–loop candidates; adjustable thresholds; pairing-arc overlay
  • Circular plasmid map — GenBank features drawn on a circular canvas; click to edit colour, name, or position; restriction sites overlaid
  • Restriction map strip — enzyme cut sites shown as a colour-coded band above the entropy ruler
  • Phylogenetic tree — neighbour-joining tree from the open alignment; click leaves to select sequences
  • BLAST integration — submit to NCBI or run against a local database; hits import directly into the alignment
  • Sequence fetch — retrieve from NCBI or UniProt by accession; comma-separate to import multiple at once
  • Six-frame translation — all six reading frames with ORFs and stop codons marked
  • Hydrophobicity profiles — Kyte–Doolittle windowed plots for membrane-region identification
  • ABI trace viewer — Sanger chromatogram display with zoom and base-call quantification
  • CLI companion — helixview-cli: stats, entropy, consensus, mi, identity, convert

Download

HelixView is free and open-source under the GPL-3.0 licence. No registration required.

Windows

Windows 10 or later, 64-bit

Download .msi
Also available: portable .exe

macOS

macOS 12 Monterey or later
Universal binary (Apple Silicon + Intel)

Download .dmg
Right-click → Open on first launch

Linux

x86-64, any modern distribution

Download AppImage
chmod +x HelixView-x86_64.AppImage && ./HelixView-x86_64.AppImage

Build from source

Requires Rust 1.77 or later.

git clone https://github.com/librebiology/helixview
cd helixview
cargo build --release
./target/release/helixview          # GUI
./target/release/helixview-cli --help
