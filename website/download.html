Windows

Windows 10 or later (64-bit). Installer sets up shortcuts and file associations automatically.

↓ Download .msi

🍎

macOS

macOS 12 Monterey or later. Universal binary (Apple Silicon + Intel). Drag HelixView.app to Applications.

↓ Download .dmg

Right-click → Open on first launch (Gatekeeper)

🐧

Linux

Any x86_64 Linux distro (Ubuntu, Fedora, Arch, etc.). AppImage — no install needed, just make it executable.

↓ Download AppImage

chmod +x HelixView-*.AppImage && ./HelixView-*.AppImage

Current release: v0.1.0 · All releases & changelogs

Command-line tools — the helixview-cli binary is included in all packages. Run helixview-cli --help in a terminal to see available commands (convert, stats, entropy, consensus, mi, identity).

Build from source

Requires Rust 1.78+ and the usual C build tools. GPU drivers with Vulkan / Metal / DX12 support are needed for the renderer. 

git clone https://github.com/librebiology/helixview
cd helixview
cargo build --release
./target/release/helixview
